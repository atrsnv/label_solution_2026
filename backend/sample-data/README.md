# Sample distributor data

## `distributor-report-2025-04.csv`

Тестовая выгрузка дистрибьютора для импорта через `/admin/finance`.
Колонки соответствуют второму поддерживаемому формату:

```
trackTitle, artistEmail, amount, period
```

Что произойдёт при импорте (с дефолтным `labelShare = 30%`):

| Трек                        | Сумма   | Лейбл (30%) | Артистам | Распределение              |
|-----------------------------|--------:|------------:|---------:|----------------------------|
| Summer Vibes (Apr)          | 4520.50 |     1356.15 |  3164.35 | vasya 100% → 3164.35       |
| Midnight Drive (Apr)        | 8730.20 |     2619.06 |  6111.14 | vasya 60% / petya 40%      |
| Lofi Dream (Apr)            | 3110.75 |      933.23 |  2177.52 | petya 100%                 |
| Summer Vibes (Mar)          | 3980.10 |     1194.03 |  2786.07 | vasya 100%                 |
| Midnight Drive (Mar)        | 2150.00 |      645.00 |  1505.00 | vasya 60% / petya 40%      |

Итого:
- Vasya получит ≈ 3164.35 + 3666.68 + 2786.07 + 903.00 ≈ **10 520.10 ₽**
- Petya получит ≈ 2444.46 + 2177.52 + 602.00 ≈ **5 223.98 ₽**

Чтобы это работало «из коробки» — `npm run seed` создаёт три трека
(`Summer Vibes`, `Midnight Drive (feat. Petya)`, `Lofi Dream`) со статусом APPROVED.
